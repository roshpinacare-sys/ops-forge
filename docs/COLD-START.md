## 1. שחזור מקומי (סדר מחייב)

```bash
# 1. שכפול — הריבונות כולה חיה בענן (39 ריפו, נמדד חי ב-/api/sovereign/estate)
git clone https://github.com/roshpinacare-sys/<repo>.git && cd <repo>

# 2. תלות
bun install

# 3. אמת-הכלכלה (Prisma/SQLite — EconState · DexPool · DexSwap · DexLpPosition)
bun run db:push

# 4. הפעלה — המיזוג הגדול על :3000
bun run dev
```

בדיקת-חיות אחת: `curl localhost:3000/api/sovereign/estate` →
`paths` אמור להחזיר אפס-שבורים, `money.consistent=true` (Σ=100,000),
`cloud.total` = ספירת-הריפו החיה. **זה ה-CI של ההגשה עצמה.**
